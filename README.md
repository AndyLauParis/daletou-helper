# 全国彩票购彩辅助工具

一个本地运行的购彩记录与开奖查询工具，覆盖体彩、福彩、足彩等 16 款彩票。提供开奖数据自动更新、号码本、中奖核对、预算支出与开奖提醒，所有数据保存在本机 SQLite，不依赖云服务。

> 本项目是**购彩辅助与记录工具**，不是购彩平台。

## 合规声明

- 不代购、不支付、不出票、不自动兑奖。
- 不预测号码、不推荐号码、不承诺中奖。
- 仅提供开奖查询、号码记录、规则核对、预算统计和站内提醒。
- 仅限 18 周岁以上成年人使用，请理性购彩、量力而行。

## 覆盖彩种

| 类别 | 彩种 |
| --- | --- |
| 体彩数字型 | 超级大乐透、排列 3、排列 5、七星彩 |
| 福彩数字型 | 双色球、福彩 3D、七乐彩、快乐 8 |
| 足彩 | 胜负彩 14 场、任选 9 场、4 场进球、6 场半全场 |
| 竞彩 | 竞彩足球、竞彩篮球（目录与支出记录） |
| 即开型 | 顶呱刮、刮刮乐（目录与支出记录） |

数字型与足彩玩法支持开奖数据抓取、号码格式校验和本地奖级核对；竞彩与即开型目前提供游戏目录和支出记录。

## 功能

- **本地账号**：注册、登录、修改密码、删除账号；密码使用 scrypt 哈希，会话令牌只保存 SHA-256 摘要。
- **开奖数据**：自动抓取官方/公开数据源，按彩种独立缓存；抓取失败时回退旧缓存并标记数据状态。
- **开奖自动更新**：有固定开奖时间的彩种在开奖后 2 小时内由后台自动重试，开奖页每 60 秒静默刷新。
- **号码本**：按彩种保存号码或投注内容，支持类别、时间筛选；已实现适配器的彩种会严格校验号码格式。
- **中奖核对**：用本地规则计算奖级，不依赖模型或预测。
- **预算与支出**：月度预算、手动支出记录、分游戏汇总、超支提示。
- **开奖提醒**：站内提醒，可设置提前 5–180 分钟；足彩等无固定开奖时间的彩种会明确提示。
- **数据导出**：导出账号业务数据为 JSON，不包含密码哈希、盐和会话令牌。
- **合规页面**：固定展示 18+、理性购彩和风险提示。

## 技术栈

- Python 3.11+（开发环境为 3.14）
- FastAPI + Uvicorn
- SQLite（Python 标准库 `sqlite3`）
- 原生 HTML / CSS / JavaScript，无前端构建、无 CDN
- requests + BeautifulSoup4/lxml 抓取公开开奖数据
- pytest 测试

## 快速开始

```bash
python3 -m venv .venv
source .venv/bin/activate

pip install fastapi uvicorn requests beautifulsoup4 lxml

python3 helper_app.py
```

打开 http://127.0.0.1:8100 ，首次使用请先注册本地账号。

测试依赖：

```bash
pip install pytest httpx
python3 -m pytest tests -q
```

仓库中还有原有的“大乐透数学实验室”，可单独运行：

```bash
python3 app.py
# http://127.0.0.1:8000
```

两个应用相互独立：辅助工具运行在 8100，实验室运行在 8000，数据文件与缓存互不覆盖。

## 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HELPER_DB_PATH` | `data/helper.db` | SQLite 数据库路径 |
| `HELPER_CACHE_DIR` | `data/cache` | 开奖数据缓存目录 |
| `HELPER_CORS_ORIGINS` | 空 | 允许的跨域来源，逗号分隔；默认关闭 CORS |
| `HELPER_DRAW_WATCH` | `1` | 设为 `0` 可关闭开奖后台自动更新 |
| `HELPER_ALLOWED_HOSTS` | `localhost,127.0.0.1` | 允许的 Host（公网部署填真实域名） |
| `HELPER_REQUIRE_HTTPS` | `0` | 设为 `1` 后 HTTP 请求 308 跳转 HTTPS |
| `HELPER_TRUSTED_PROXIES` | `127.0.0.1,::1` | 受信反向代理，用于解析真实 IP |
| `HELPER_SESSION_TTL_DAYS` | `7` | 会话有效期（天） |
| `HELPER_REGISTRATION_MODE` | `open` | `open` / `invite` / `closed` |
| `HELPER_INVITE_CODE` | 空 | `invite` 模式下的邀请码 |
| `HELPER_RATE_GLOBAL_PER_MINUTE` | `600` | 单 IP 全局限流 |
| `HELPER_RATE_AUTH_PER_MINUTE` | `30` | 登录/注册严格限流 |
| `HELPER_RATE_EXPENSIVE_PER_MINUTE` | `60` | 抓取/重计算接口严格限流 |
| `HELPER_MAX_BODY_BYTES` | `262144` | 请求体大小上限 |

服务默认只监听 `127.0.0.1:8100`，不对局域网或公网开放。公网部署请按 [deploy/README.md](deploy/README.md) 配置 HTTPS、反向代理、限流与访问控制。

## 数据更新机制

- 每个彩种独立缓存，默认有效期 6 小时，最多保留 200 期。
- 后台线程每 60 秒检查一次；开奖后 2 小时内持续尝试，同一彩种每 3 分钟最多抓取一次。
- 缓存中已有当天开奖记录时停止重试，避免无意义请求。
- 大乐透复用原有 `core.store`，刷新时先更新其数据源，再读取最近开奖。
- 足彩、竞彩、即开型没有固定开奖时间，仍由用户手动刷新。
- 上游发布存在延迟，实际更新时间取决于官方数据源，通常为开奖后 5–30 分钟。
- 当前以开奖号码为主，奖池、一等奖注数、各奖级金额尚未完整覆盖。

## 安全与隐私

- 密码使用 scrypt 加盐哈希，数据库不保存明文密码。
- 会话令牌由安全随机数生成，数据库只保存 SHA-256 摘要，默认 7 天过期。
- 会话令牌保存在 `HttpOnly` + `SameSite=Lax` Cookie 中，前端 JavaScript 无法读取；HTTPS 下自动加 `Secure`。
- 登录失败按“IP + 用户名”限流，并记录成功/失败审计日志；改密后旧会话全部失效。
- 统一安全响应头：CSP、HSTS（HTTPS）、X-Frame-Options、X-Content-Type-Options 等。
- 请求层防护：路径探测/扫描器拦截、危险方法拒绝、URL 与请求体大小限制、按 IP 滑动窗口限流。
- 支持 `invite` / `closed` 注册模式，公网部署可关闭公开注册。
- 导出数据不包含密码哈希、盐和会话令牌。
- 无第三方统计、无外部 CDN，页面资源全部本地加载，CSP 不依赖 `unsafe-inline` 脚本。
- 仅监听本机回环地址；公网部署方式见 [deploy/README.md](deploy/README.md)。
