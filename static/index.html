02 MODEL 01 / 期望与凯利

期望值决定方向，凯利决定仓位。

对数增长曲线

g(f)：下注比例与长期增长

f = 0 时 g = 0

曲线在 f = 0 处达到最大值 0；任何正仓位都位于负增长区。标记线为 0.1% / 1% / 5% / 50% / 100%。

公式与推导

凯利公式

f* = (b · p − q) / b = p − q / b

其中 p 为头奖概率，q = 1 − p，b 为净赔率（赢时每 1 元净赚多少）。当 p · b < q 时 f* < 0，代表这个赌局对下注者不利。

对数增长率

g(f) = p · ln(1 + f · b) + q · ln(1 − f)

g(f) 是每期资金的对数增长率。最优仓位让 g′(f) = 0；当 g′(0) = p · b − q < 0 时，最优仓位就是 0，而不是“小注试试”。当 f → 1 时 g(f) → −∞：全仓下注一旦未中即归零，长期增长率为负无穷。

净赔率口径

b = (头奖奖金 − 单注成本) / 单注成本

以 2 元单注、500 万元头奖为例，b = 2,499,999。把二等奖及以下奖级也纳入后，可以把每个奖级视为独立“赢”的结果，用多奖级判据检验。

多奖级判据

g′(0) = Σ pᵢ · bᵢ = 返奖率 − 1

把 7 个奖级全部计入，g′(0) 仍等于返奖率减 1。当前规则返奖率 51%，所以 g′(0) = −0.49 < 0，最优仓位仍为 0。

组合计数

C(35,5) × C(12,2) = 324,632 × 66 = 21,425,712

一等奖概率为 1 / 21,425,712；7 个奖级由 13 个中奖条件归并，中奖组合合计 1,429,197，任意奖级中奖率约 6.67%。

数据来源

历史开奖取自 500.com 大乐透历史数据页，首次启动自动抓取并写入本地缓存；页面顶部显示缓存期数、最新期号与抓取时间，参数与结论均可复现。

04 MODEL 03 / 倍投

倍投不是策略，是加速破产。

输一把就翻倍，听起来只要本金够厚就能等到赢。可本金有限、期数有限、单注上限有限；只要期望为负，倍投只改变你亏完的路径，不改变终点。

理想化假设 本模拟采用对倍投最有利的 1:1 回本假设：赢一把即可收回此前所有投入并净赚初始注额；不设投注上限、不抽水、不封顶。

          把“预测”换成“验证”

          • 用公式、历史数据与蒙特卡洛三重证据交叉验证同一个结论。
          • 把“冷热号”放回置信带里看，承认随机波动。
